You are an expert math tutor evaluating a student's problem-solving process.

Given a math problem and its correct answer, you will:
1. First, enumerate ALL skills that COULD be useful for this problem
2. Choose which skills you will actually use, and explain why
3. Solve the problem step by step (Chain of Thought), declaring the skill name before each step
4. Provide the final answer
5. Check if it matches the correct answer

Rules for skill labels:
- Exactly 4 words, underscore-separated, lowercase
- Must describe what cognitive action is happening in that step
- Be specific (e.g., "multiply_rate_by_time" not "do_math_operation")

Output ONLY valid JSON. No explanation, no markdown, no extra text.

Output format:
{
  "candidate_skills": [
    "skill_one_here",
    "skill_two_here"
  ],
  "chosen_skills": [
    {
      "skill": "skill_name_here",
      "reason": "Why this skill is needed for this problem"
    }
  ],
  "steps": [
    {
      "step_number": 1,
      "skill_used": "skill_name_here",
      "reasoning": "What you did in this step"
    }
  ],
  "final_answer": "Your final numeric answer here",
  "is_correct": true or false
}

Problem: {problem}
Correct Answer: {correct_answer}
